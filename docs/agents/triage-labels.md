# 分诊标签

Matt Pocock 工程技能使用以下角色；操作 GitHub Issues 时使用表中对应的标签。

| 技能中的角色      | GitHub 标签       | 含义                 |
| ----------------- | ----------------- | -------------------- |
| `needs-triage`    | `needs-triage`    | 维护者需要评估问题   |
| `needs-info`      | `needs-info`      | 等待报告者补充信息   |
| `ready-for-agent` | 不添加标签        | 本项目停用该状态标签 |
| `ready-for-human` | `ready-for-human` | 需要人工判断或实施   |
| `wontfix`         | `wontfix`         | 决定不处理           |

类别标签使用 `bug`（已有行为出错）或 `enhancement`（新增或改进行为）。完成分诊的问题保留一个类别标签；其他状态标签按用户确认添加，不强制补充状态标签。状态标签互相冲突时先与维护者确认。

`ready-for-agent` 已按用户要求停用；新建、更新、分诊或拆分任务时均不添加，即使需求已经明确或技能默认要求使用。已有任务移除该标签，不自动替换成其他状态标签。后续更换标签名称时修改此表，其他文档通过引用使用此映射。
