# 管理端前端

独立桌面 Web 应用 `apps/admin`（`@hehuoda/admin`），交付 Issue #36 的前端工程、共享布局、登录、工作台、操作记录与业务导航。真实管理员服务由 #37 提供，认证守卫、HTTP 接线与完整联调由 #46 承接。

## 启动与质量检查

使用仓库要求的 Node.js 24（至少 24.15.0）和 pnpm 10.30.3：

```bash
pnpm install --frozen-lockfile
pnpm dev:admin
pnpm --filter @hehuoda/admin lint
pnpm --filter @hehuoda/admin typecheck
pnpm --filter @hehuoda/admin build
pnpm --filter @hehuoda/admin test:unit
pnpm format:check
```

默认地址为 `http://127.0.0.1:5183/`，学生端和 API 仍使用原 `pnpm dev`，互不改变启动行为。管理端独立产物为 `apps/admin/dist`；History 路由部署需将应用路径回退到 `index.html`。`apps/admin/.env.example` 提供可选的学生端链接，不涉及认证配置。

## 页面与交付边界

| 路由                                             | 页面                       | 当前行为                                         |
| ------------------------------------------------ | -------------------------- | ------------------------------------------------ |
| `/`                                              | 工作台                     | 默认统计待接入，布局示例需单独展开               |
| `/login`                                         | 登录                       | 必填校验、键盘可用的密码显隐、提交中与失败反馈   |
| `/operations`                                    | 操作记录                   | 明确服务未开放，固定示例可搜索、按类型筛选和分页 |
| `/competitions`、`/sources`、`/runs`、`/reviews` | 比赛、来源、运行、候选审核 | 导航及待接入页面                                 |
| `/notifications`、`/users`、`/teams`、`/reports` | 通知、用户、招募、举报     | 导航及待接入页面                                 |
| 其他路径                                         | 页面 404                   | 返回工作台入口，与服务不可用分开表达             |

所有页面常驻“页面预览，未认证”。不生成 Token、Cookie、模拟身份或认证成功跳转；账号密码仅存在组件内存，提交结束清空密码，离开页面销毁表单。固定示例不记录实际业务操作，不发送管理请求或改变数据库；刷新不恢复模拟身份。

`src/services.ts` 是登录与工作台的可注入视图适配入口，默认抛出明确的 `ServiceUnavailable`。它不预设 HTTP 路径；#46 应依据 #37 合并后的 OpenAPI 类型实现映射并接入真实认证。工作台统计的 `null` 表示未知，“0”表示接口返回的真实零值；加载、失败、重试、空待办与服务未开放由组件测试覆盖，测试注入不作为已完成真实联调的证据。

操作记录默认没有真实数据，展开后是 12 条明确标注的固定样例，每页 8 条。搜索和类型筛选会重置页码；表格宽于内容区时仅表格内部横向滚动。Element Plus 与 Tailwind 仅由管理应用加载，Tailwind 扫描限定在管理端源码内。

## 设计与平台范围

沿用品牌绿 `#27644b`、背景 `#f4f6f5`、白色表面、正文 `#243d32`、分隔 `#e6eae7`，采用微软雅黑/PingFang 中文字体。固定侧栏、左对齐内容、文字状态与独立表格滚动适用于桌面内容管理；目标浏览器视口为 1024px 和 1440px。

本应用只交付桌面 Web，Element Plus、DOM、Vue Router History 和 Web CSS 不作为学生端 uni-app H5／微信小程序的复用前提。本次不修改学生端公开响应，也不增加其运行时依赖；后续若迁移管理能力，应单独选择跨端组件、导航、请求与弹层方案，并验证微信运行时。本次没有 mp-weixin 改动，不适用微信开发者工具人工验收。

实际验证结果写入交付 PR；截图、验收脚本、状态测试页面与原有业务演示备份仅保留本地，不提交 Git。
