# 管理端前端

独立桌面 Web 应用 `apps/admin`（`@hehuoda/admin`）。#173 接通管理员 Cookie 会话、工作台、操作审计、原两院采集及候选审核／导入／发布。比赛独立编辑与用户、招募、举报治理仍分别等待其后端接线；此任务不表示 #46 全范围完成。生产部署和官网实站覆盖另行验收。

## 启动与质量检查

使用仓库要求的 Node.js 24（至少 24.15.0）和 pnpm 10.30.3：

```bash
pnpm install --frozen-lockfile
pnpm dev:admin
pnpm --filter @hehuoda/admin lint
pnpm --filter @hehuoda/admin typecheck
pnpm --filter @hehuoda/admin build
pnpm --filter @hehuoda/admin test:unit
pnpm format:check
```

默认地址为 `http://127.0.0.1:5183/`，学生端和 API 仍使用原 `pnpm dev`，互不改变启动行为。管理端独立产物为 `apps/admin/dist`；History 路由部署需将应用路径回退到 `index.html`。`apps/admin/.env.example` 提供可选的学生端链接，不涉及认证配置。

## 页面与交付边界

| 路由                                                                                                 | 页面                 | 当前行为                                                                      |
| ---------------------------------------------------------------------------------------------------- | -------------------- | ----------------------------------------------------------------------------- |
| `/`                                                                                                  | 工作台               | 会话恢复后查询真实统计，含 scope/asOf；布局示例需单独展开                     |
| `/login`                                                                                             | 登录                 | 必填校验、键盘可用的密码显隐、提交中与失败反馈                                |
| `/operations`                                                                                        | 操作记录             | 查询真实管理审计，类型筛选、分页及详情                                        |
| `/competitions`、`/competitions/new`、`/competitions/:id`、`/competitions/:id/edit`                  | 比赛届次维护         | 公开查询及独立管理示例，写服务待接入                                          |
| `/ingestion/sources`、`/ingestion/runs`、`/ingestion/runs/:id`                                       | 来源与运行追溯       | 真实来源、扫描受理、运行查询与续跑；`/sources`、`/runs` 为跳转入口            |
| `/ingestion/candidates`、`/ingestion/candidates/:id`、`/ingestion/notices`、`/ingestion/notices/:id` | 候选审核与通知版本   | 真实审核／修正／批准／导入／发布与通知历史；`/reviews` 跳转候选列表           |
| `/users`、`/recruitments`、`/reports` 及各自 `/:id`                                                  | 用户、招募与举报治理 | 列表／详情及示例交互已实现，真实管理写入未开放；`/teams` 跳转 `/recruitments` |
| `/notifications`                                                                                     | 通知管理             | 待接入占位                                                                    |
| 其他路径                                                                                             | 页面 404             | 返回工作台入口，与服务不可用分开表达                                          |

除 `/login` 外，管理路由均先恢复真实会话；匿名访问跳转登录，成功后仅恢复本站安全路径。密码仅保留在组件内存并在请求结束清空；Cookie 由服务端 HttpOnly 管理，CSRF 仅存内存。401 撤销页面状态、预览与在途请求，旧响应不能恢复旧身份；403 显示无权限，409 保留输入并要求重新载入。退出网络失败时仍清理本地状态，显式重试先恢复 CSRF 再撤销服务端会话。

同一浏览器的多个管理标签页共享 Cookie，因此按管理员身份而非标签页判断归属：管理响应携带 `X-Admin-Id`，与当前会话不符时不接收该响应并清理旧身份；`/auth/csrf` 的 `adminId` 必须与 `/auth/session` 一致，否则按切换处理。登录或退出通过同源 `BroadcastChannel` 通知其他标签页立即作废本地会话、预览回执和在途请求，由各自路由守卫跳转登录并保留返回地址；迟到响应不能把已作废的旧身份或旧数据带回页面。

`http.ts` 为同源请求与会话入口，`adapters.ts` 依据生成 OpenAPI 映射页面模型。`main.ts` 注入真实服务；候选和采集页面显式 `preview=1` 优先使用隔离只读适配，不能调用真实写服务。示例数据单独成模块并按需动态加载，正式登录路径不加载示例内容，也不会因示例模块缺失而影响真实查询。通知追溯不提供固定示例，该标记下不读取真实通知。正式登录页面不显示未认证预览横幅。示例也要求管理路由认证；它不替代业务权限。

工作台只展示服务端 available/count/scope/asOf，未知值不补零；逐模块显示中文名称、服务端范围与统计截止时间（按北京时间格式化，不显示原始 ISO 串），未接入的独立治理模块仍显示不可用。操作记录使用 `/api/v1/admin/operations` 列表及详情，不以本地记录补缺。管理配置、初始化和开发 Origin 要求见[管理员认证说明](admin-auth.md)；本地代理默认 API 为 `http://127.0.0.1:3001`。

## 设计与平台范围

沿用品牌绿 `#27644b`、背景 `#f4f6f5`、白色表面、正文 `#243d32`、分隔 `#e6eae7`，采用微软雅黑/PingFang 中文字体。固定侧栏、左对齐内容、文字状态与独立表格滚动适用于桌面内容管理；目标浏览器视口为 1024px 和 1440px。

本应用只交付桌面 Web，Element Plus、DOM、Vue Router History 和 Web CSS 不作为学生端 uni-app H5／微信小程序的复用前提。本次不修改学生端公开响应，也不增加其运行时依赖；后续若迁移管理能力，应单独选择跨端组件、导航、请求与弹层方案，并验证微信运行时。本次没有 mp-weixin 改动，不适用微信开发者工具人工验收。

实际验证结果写入交付 PR；截图、验收脚本、状态测试页面与原有业务演示备份仅保留本地，不提交 Git。

## 比赛届次维护（#42）

比赛列表与详情默认查询管理适配入口，#38 尚未开放时显示真实不可用反馈；显式 `preview=1` 才读取独立样例。公开查询区域复用现有 `/api/v1/colleges`、`/competitions`、`/competitions/:id` 的生成类型、真实 GET 与失败重试，不回退示例，不将已发布公开子集当成完整管理目录。公开详情只读，真实维护必须重新读取管理基线。

`console/competitions.ts` 是独立页面模型，#38/#46 合并契约后再用生成类型映射。新增只能保存草稿；现有届次的保存、发布、隐藏分别选择与确认，切换对象清除动作与预览。预览绑定完整内容、动作和基线；修改输入后失效，已发布更新须明确勾选并使用专门确认。无服务端凭据的布局预览不授权写入，保存、发布、隐藏均明确未执行。409 保留待核对输入并锁定本轮操作，须重新读取基线；403 与其他失败不提示成功，提交中不可重复或离页。

表单分别维护 organizer、来源 publisher、赛段 hosts 和参赛范围，unknown 不自动变为全校。各类时间保留 instant/date/unknown，具体时刻含时区，日期不补时刻。赛段来源必须属于当前届次，ID/日期/学院/人数规则有校验与错误定位。未变关系省略，修改关系数组完整替换，空数组明确清空关系；不提供删除届次、归档或编辑学院字典。差异同时展示字段与嵌套关系，未保存关闭/离页有提示。

此任务不修改公开响应或学生端，不向普通 uni-app H5/微信小程序迁入 Element Plus、DOM、History、AbortSignal 或管理写能力。跨端公开请求、外链与时间展示仍按迁移待办单独验证，管理端浏览器检查不能替代目标端验收。

## 用户、招募与举报治理（#45）

`/users`、`/recruitments`、`/reports` 提供列表，`/:id` 子路径提供详情；旧 `/teams` 管理入口重定向到 `/recruitments`。查询参数保留搜索、合法状态、日期范围、page/pageSize 与 `preview=1` 示例标记，详情返回列表恢复原查询。真实查询服务默认未开放，显式切换后才显示独立管理样例；不读取学生端演示参与者或会话作为管理数据。

用户业务状态和账号限制、招募业务状态和后台隐藏、举报处理状态和结论分别展示。限制/恢复、隐藏/恢复和举报处理各自打开理由确认；举报结论不会自动触发账号或招募制裁，不提供私人联系方式、密码、Session 或代替队长审批等操作。

`console/governance.ts` 为 #41/#46 接线预留视图适配边界。变更材料包含稳定对象 ID、trim 后理由、版本、基线及本次确认的 operationId，不填写可信操作者。默认与样例写适配都提示“服务未开放，未执行”，不修改样例；403 提示权限不足，409 要求重新加载和重新审核，其他异步错误不冒充成功。请求代次使旧查询/详情不能覆盖新视图，查询改变立即清理旧详情。每次确认中禁用重复提交；理由超过 1000 字或为空不能提交，取消不产生成功状态。

本功能仅桌面 Web，未修改公开招募响应，不新增学生端 H5/微信小程序适配；未来公开接口变化由实际契约任务登记。桌面 1024/1440px 的表格内部滚动、长标题/理由、对话框键盘与焦点应纳入交付验收，结果记录在 PR。

## 候选审核与通知追溯（#173）

`/ingestion/candidates` 列表支持审核状态、日期和分页；当前 HTTP 不支持自由标题搜索，因此真实模式不展示该输入。详情读取当前候选、服务端审核文件与通知最新版本；历史正文从 `/ingestion/notices/:id` 查看，版本列表分页，原文与差异始终按纯文本展示，外链仅接受无凭据 HTTP(S)。

材料原样保留 format=1/2、mappingBaseline、evidenceRevision 及证据扩展，只编辑 batch、checkedAt、resolution。页面草稿从 formalBefore 继承未提供字段，提交仅发送原补丁及实际改动，避免局部补丁变成清空。保存后修订增加、批准失效，成功动作重新读取真实材料。拒绝／重开使用候选状态基线；导入／发布使用正式基线。两个基线不能互换。

批准不导入，导入不发布；新建草稿、更新草稿与更新已发布分别核对。导入和独立发布各自获取服务端 previewId 及变更摘要，并绑定同一材料；编辑、目标变化、409 或重新载入均使确认失效。已发布更新要求明确勾选及专门确认；公开数据在确认前保持原状。写操作中禁止重复提交及路由离开；迟到查询／预览不能覆盖其他对象。

本任务复用 #175/#176 已合并的只读材料，不实现附件管理、分类修改或新学院页面（#177）。不导入服务端采集包，不修改学生端 H5／微信小程序 UI；管理浏览器、真实 API／数据库、官网实站及生产证据分别记录，不能互代。
