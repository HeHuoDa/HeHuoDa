# 管理端前端

独立桌面 Web 应用 `apps/admin`（`@hehuoda/admin`）。截至 2026-10-23，核对 main `4dae578c38465993949538839a559100d4c11150` 与 GitHub：#36、#42–#45 已关闭，前端工程、登录／工作台／操作记录，以及比赛、采集、候选审核和治理页面均已交付。#37–#41、#46 仍开放：真实管理员认证审计、管理 HTTP 接口与完整联调尚未完成。公开比赛 GET 与固定示例必须分开表达，不能用 `preview=1` 证明管理服务可用。本次仅核实源码和跟踪器，未新增浏览器或真实服务验收。

## 启动与质量检查

使用仓库要求的 Node.js 24（至少 24.15.0）和 pnpm 10.30.3：

```bash
pnpm install --frozen-lockfile
pnpm dev:admin
pnpm --filter @hehuoda/admin lint
pnpm --filter @hehuoda/admin typecheck
pnpm --filter @hehuoda/admin build
pnpm --filter @hehuoda/admin test:unit
pnpm format:check
```

默认地址为 `http://127.0.0.1:5183/`，学生端和 API 仍使用原 `pnpm dev`，互不改变启动行为。管理端独立产物为 `apps/admin/dist`；History 路由部署需将应用路径回退到 `index.html`。`apps/admin/.env.example` 提供可选的学生端链接，不涉及认证配置。

所有页面常驻“页面预览，未认证”。不生成 Token、Cookie、模拟身份或认证成功跳转；账号密码仅存在组件内存，提交结束清空密码，离开页面销毁表单。固定示例不记录实际业务操作，不发送管理请求或改变数据库；刷新不恢复模拟身份。

`src/services.ts` 是登录与工作台的可注入视图适配入口，默认抛出明确的 `ServiceUnavailable`。它不预设 HTTP 路径；#46 应依据 #37 合并后的 OpenAPI 类型实现映射并接入真实认证。工作台统计的 `null` 表示未知，“0”表示接口返回的真实零值；加载、失败、重试、空待办与服务未开放由组件测试覆盖，测试注入不作为已完成真实联调的证据。

操作记录默认没有真实数据，展开后是 12 条明确标注的固定样例，每页 8 条。搜索和类型筛选会重置页码；表格宽于内容区时仅表格内部横向滚动。Element Plus 与 Tailwind 仅由管理应用加载，Tailwind 扫描限定在管理端源码内。

## 设计与平台范围

沿用品牌绿 `#27644b`、背景 `#f4f6f5`、白色表面、正文 `#243d32`、分隔 `#e6eae7`，采用微软雅黑/PingFang 中文字体。固定侧栏、左对齐内容、文字状态与独立表格滚动适用于桌面内容管理；目标浏览器视口为 1024px 和 1440px。

本应用只交付桌面 Web，Element Plus、DOM、Vue Router History 和 Web CSS 不作为学生端 uni-app H5／微信小程序的复用前提。本次不修改学生端公开响应，也不增加其运行时依赖；后续若迁移管理能力，应单独选择跨端组件、导航、请求与弹层方案，并验证微信运行时。本次没有 mp-weixin 改动，不适用微信开发者工具人工验收。

实际验证结果写入交付 PR；截图、验收脚本、状态测试页面与原有业务演示备份仅保留本地，不提交 Git。

## 比赛届次维护（#42）

比赛列表与详情默认查询管理适配入口，#38 尚未开放时显示真实不可用反馈；显式 `preview=1` 才读取独立样例。公开查询区域复用现有 `/api/v1/colleges`、`/competitions`、`/competitions/:id` 的生成类型、真实 GET 与失败重试，不回退示例，不将已发布公开子集当成完整管理目录。公开详情只读，真实维护必须重新读取管理基线。

`console/competitions.ts` 是独立页面模型，#38/#46 合并契约后再用生成类型映射。新增只能保存草稿；现有届次的保存、发布、隐藏分别选择与确认，切换对象清除动作与预览。预览绑定完整内容、动作和基线；修改输入后失效，已发布更新须明确勾选并使用专门确认。无服务端凭据的布局预览不授权写入，保存、发布、隐藏均明确未执行。409 保留待核对输入并锁定本轮操作，须重新读取基线；403 与其他失败不提示成功，提交中不可重复或离页。

表单分别维护 organizer、来源 publisher、赛段 hosts 和参赛范围，unknown 不自动变为全校。各类时间保留 instant/date/unknown，具体时刻含时区，日期不补时刻。赛段来源必须属于当前届次，ID/日期/学院/人数规则有校验与错误定位。未变关系省略，修改关系数组完整替换，空数组明确清空关系；不提供删除届次、归档或编辑学院字典。差异同时展示字段与嵌套关系，未保存关闭/离页有提示。

此任务不修改公开响应或学生端，不向普通 uni-app H5/微信小程序迁入 Element Plus、DOM、History、AbortSignal 或管理写能力。跨端公开请求、外链与时间展示仍按迁移待办单独验证，管理端浏览器检查不能替代目标端验收。

## 用户、招募与举报治理（#45）

`/users`、`/recruitments`、`/reports` 提供列表，`/:id` 子路径提供详情；旧 `/teams` 管理入口重定向到 `/recruitments`。查询参数保留搜索、合法状态、日期范围、page/pageSize 与 `preview=1` 示例标记，详情返回列表恢复原查询。真实查询服务默认未开放，显式切换后才显示独立管理样例；不读取学生端演示参与者或会话作为管理数据。

用户业务状态和账号限制、招募业务状态和后台隐藏、举报处理状态和结论分别展示。限制/恢复、隐藏/恢复和举报处理各自打开理由确认；举报结论不会自动触发账号或招募制裁，不提供私人联系方式、密码、Session 或代替队长审批等操作。

`console/governance.ts` 为 #41/#46 接线预留视图适配边界。变更材料包含稳定对象 ID、trim 后理由、版本、基线及本次确认的 operationId，不填写可信操作者。默认与样例写适配都提示“服务未开放，未执行”，不修改样例；403 提示权限不足，409 要求重新加载和重新审核，其他异步错误不冒充成功。请求代次使旧查询/详情不能覆盖新视图，查询改变立即清理旧详情。每次确认中禁用重复提交；理由超过 1000 字或为空不能提交，取消不产生成功状态。

本功能仅桌面 Web，未修改公开招募响应，不新增学生端 H5/微信小程序适配；未来公开接口变化由实际契约任务登记。桌面 1024/1440px 的表格内部滚动、长标题/理由、对话框键盘与焦点应纳入交付验收，结果记录在 PR。

## 候选审核与通知追溯（#44）

路由为 `/ingestion/candidates`、`/ingestion/candidates/:id`、`/ingestion/notices`、`/ingestion/notices/:id`，原 `/reviews` 重定向到候选列表。列表支持搜索、状态、时间范围、分页；版本由 `version` 查询参数选择，目标届次通过 `target` 重新载入；`preview=1` 仅启用独立页面样例。历史版本只读，不沿用旧证据审核新内容。

`console/review.ts` 的页面模型对齐服务端 `ReviewFile` 结构，不宣称 #40 HTTP DTO 已存在。source、article、previousArticle、candidate 证据、formalBefore、sourceVersion、candidateRevision 和 baseline 只读；人工修正仅修改 batch、checkedAt、resolution。目标届次变更须重新载入材料及正式基线；新材料不沿用旧批准。人工日期不从采集时间推导，未知学院、资格与时间不自动补齐；承办与发布单位、参赛范围、报名开始/截止、材料截止/比赛时间分开展示。原文按纯文本展示，不注入 HTML；来源和附件仅允许无凭据 HTTP(S) 链接，附件不自动下载或解析。

新建草稿、更新草稿、更新已发布比赛的差异分别展示。批准不等于导入、导入不等于发布；已导入不可拒绝，拒绝候选仅能显式重开。布局预览绑定完整材料签名，任何内容变更后失效；导入与独立发布各自预览和确认。已发布更新需同内容预览、明确勾选和专门确认文案，服务适配收到显式 confirmPublished 标记。布局预览不产生服务授权：默认预览/写服务未开放，缺少匹配的服务端预览回执时不能执行写入，不把操作更新为成功。403/409 和异步错误保留输入，409 要求重新加载/导出与重新审核。未保存离页需明确丢弃，关闭页面使用浏览器原生提示；请求代次隔离迟到版本和预览响应。

公开学院、比赛列表与详情通过 `/api/v1/colleges`、`/api/v1/competitions`、`/api/v1/competitions/:id` 的现有 OpenAPI 类型及真实 GET 请求接入；不读取管理目录或附带会话凭据。开发代理和学生端一致，默认 `http://127.0.0.1:3001`，可用 `API_PROXY_TARGET` 调整。API/数据库须单独按仓库说明运行；不可达、结构错误或取消均不伪装成功或空列表。公开列表不包含草稿/隐藏比赛，不能当全部管理目录；选择公开对象后仍重新请求核对材料及基线。管理查询、审核和真实授权由 #40/#46 接入，操作身份来自未来服务端而非人工填写。

#44 分支基于 #45 的列表、查询和理由确认组件；两个 Issue 保持独立提交。管理原文、差异、浏览器 AbortController/History/DOM 和 Element Plus 仅用于桌面 Web，不作为学生端 uni-app 的 H5/微信复用模块；本次没有公开响应或用户端改动，不新增小程序运行验收要求。真实联调、生产状态与目标端验证按各自后续任务记录，不能从 Web 示例或编译结果推断。

服务端已有目标导出的 batch 是局部补丁（例如仅有 id/notices）。`console/review-draft.ts` 从 formalBefore 继承未提供的字段供编辑，序列化时仅提交原有补丁和确实改动的字段；未编辑的批准材料保持原始结构，不把省略字段当作清空。赛段/赛道关系遵循既有导入器的合并语义，移除已有关系的修正会还原正式值，不提供删除正式关系的假能力。409 会使确认材料和预览回执失效，重新载入前禁用本轮与后续写操作，防止继续提交旧基线。
